# Plugin Desk

Codex chrome extension setup is three clicks in theory. In practice a lot of people open the plugin directory, scroll to C, and find no Chrome entry at all.

**Read the full page:** https://codex-chrome-extension.github.io/

If the documentation told you to open Plugins and add Chrome, and there is no Chrome plugin in your directory, you are not doing it wrong and your install is not corrupted. That exact situation was raised in OpenAI's own developer forum in May, with the poster listing the neighbouring entries to prove the gap, and it drew a support reply. Below is the documented path, the permission model the plugin actually governs, and the checks worth running before you open a ticket. If your reason for wanting browser control was cloning a page's layout, Begin.sh does that from a URL with no extension involved.
